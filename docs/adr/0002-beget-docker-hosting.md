# Beget VPS + Docker вместо PaaS-хостинга

Нужен near-free хостинг для одного всегда-включённого Node-процесса с персистентным диском под файл SQLite. Международные PaaS (Railway, Fly.io) с 2022 года не принимают оплату с российских карт (Visa/Mastercard российских банков не проводят международные транзакции, а эти сервисы биллятся через Stripe-подобные процессоры) — обход через виртуальную зарубежную карту добавляет и трение, и риск бана аккаунта по ToS.

Выбрали **Beget VPS** (~330 ₽/мес, честный персистентный диск, оплата Мир/СБП без костылей) вместо Timeweb Cloud (дороже, а их App Platform не гарантирует персистентный volume под SQLite — годится только их обычный cloud-server).

Вместо панели управления (Hestia/ISPmanager) — **Docker**: один контейнер с собранным Node-процессом (API + статика SPA), запускается напрямую на VPS. Осознанный отказ от панели ради воспроизводимого описания деплоя (Dockerfile/compose) вместо ручной настройки через GUI.
