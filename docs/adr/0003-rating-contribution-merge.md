# Рейтинг и Вклад — одна историзированная сущность, не две

В игре «рейтинг» и «вклад в дуэль альянса» — одно и то же число (очки дуэли за неделю), которое в приложении случайно оказалось представлено двумя параллельными таблицами (`rating_weeks`/`weekly_rating_entries` и `contribution_entries`) с разным поведением: первая копит историю по неделям, вторая при каждом импорте полностью заменяет данные.

Решили оставить только `contribution_entries`, добавив на неё дату недели (`weekStart`) для историзации, и убрать `rating_weeks`/`weekly_rating_entries` целиком. Экраны «Рейтинг игроков» (история по неделям) и «Анализ вклада» (последняя неделя) остаются как есть — оба читают одну и ту же историю, различие только в срезе по времени, который берёт конкретный экран.

Поле `group` (R1–R5) в объединённой сущности не хранится — вклад отражает только очки за неделю, а не то, к какой группе игрок принадлежал в тот момент; группа доступна живьём через `players.group`.
