# Дуэльная/силовая статистика профиля — вычисляется, не заливается CSV

Таблица `player_stats` (`avgDuelScore`, `avgDuelRank`, `strongerThanPercent`, `weeklyPowerChangePercent`) была добавлена по аналогии с другими CSV-снапшотами без обсуждения с пользователем — цифры вписывались вручную и выглядели как расчётная аналитика, хотя ей не являлись.

Решили упразднить `player_stats` и CSV-ресурс `player-stats` целиком, заменив все 4 поля вычисляемыми величинами: `strongerThanPercent` считается на лету по живой сумме мощи отрядов (`squads.powerM`) относительно остальных игроков альянса; `avgDuelScore`/`avgDuelRank` — среднее по историзированному Вкладу (см. ADR 0003); `weeklyPowerChangePercent` требует сравнения с прошлым состоянием мощи, для чего вводится отдельная сущность «срез мощи» — периодическая ручная фиксация мощи всех игроков разом по действию офицера в UI, не CSV и не по расписанию (в проекте нет инфраструктуры под cron).

Срез мощи — самостоятельная сущность с собственным кадансом, не привязанная к неделям Вклада: офицер может фиксировать мощь чаще или реже раза в неделю, независимо от того, когда заливается Вклад.
