# Стиль игры игрока — одно поле, не два

`players.playstyle` (3 кириллических значения) и `formationTiles.role` (`FormationRole`, 4 латинских значения) описывали один и тот же атрибут игрока двумя разными типами с разным набором значений — расхождение, замеченное только при пересмотре профиля, а не осознанное архитектурное решение.

Решили оставить одно поле — `players.playstyle` — со значениями из бывшего `FormationRole` (`attacker`/`defender`/`mixed`/`none`), т.к. этот набор уже включал недостающее в старом `Playstyle` состояние «без стиля». `formationTiles.role` убирается — формация читает стиль игрока из `players.playstyle` по нику. Русские подписи в UI (рашер/куколд/флоатер/афк) — только отображение, не значения в БД.
