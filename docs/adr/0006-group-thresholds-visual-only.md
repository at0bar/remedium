# Пороги групп R1/R2/R3 — только визуальный ориентир, не авто-назначение группы

При обсуждении настраиваемых порогов очков Вклада для перехода между группами возник соблазн сразу сделать переход автоматическим. Осознанно решили этого не делать: `PlayerGroup` остаётся полем, которое вручную меняет игрок с правом редактирования — пороги лишь рисуют ориентировочные линии на шкале Вклада и настраиваются через новую вкладку «Настройки» в разделе «Альянс» (видна только при `canEdit`).

Автоматизация перехода — отдельное решение на будущее (нужно продумать пограничные случаи вроде колебания очков туда-обратно у границы порога), в этой сессии сознательно отложено. Порог не применим к R4/R5 — этот переход управляется независимо от очков Вклада.
